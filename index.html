Room library

Each room prompt = room description + Style Anchor + negative. Generate the empty plate first (no people), then a version with staff. Empty plates are what editors use for B-roll, transitions and compositing.

Shortcut for medium plates: if the tool keeps returning a wide view, take the approved wide image and crop a 16:9 area from the bottom of it (ceiling out, desk or main furniture filling the frame), then upscale to 1920×1080. A crop keeps the room 100% identical. A016 was made this way.

Props & fixtures: isolated asset prompts

Product-style renders of each object on a seamless seafoam backdrop. Use them for inserts, compositing and as extra references when a room generation drifts.

ASSET WRAPPER (append to every prop prompt)

Scenes with people: rooms + cast together

Built after the room plates, uniforms and agent poses exist. Each scene attaches the room plate, the person's reference and the previous scene in the same room, so the clinic and the cast stay identical from shot to shot.

Consistency QA: reject if any fail

    Tool notes

    • Reference-capable image models (Midjourney, Flux Kontext, GPT-image, Gemini image, Ideogram): always upload REF-01 for environment and REF-02 for Annie. Start prompts with “Match the environment, colours and lighting of the reference image exactly.”
    • Midjourney: use --sref with REF-01 and the omni/character reference (--oref in V7) with REF-02; add --style raw. Reuse one seed per room for plates. Parameter names change between versions, so confirm against current docs.
    • Image-to-video (Kling, Runway, Veo, Hailuo, Pika): animate approved stills only, 5–10 s clips, describe motion only (the still already carries the look), and keep “static camera” or one slow move.
    • Long scenes: take the last frame of a clip as the first frame of the next to chain continuous shots.
    • All people are AI-generated characters; do not use real staff or patient likenesses without signed releases.
